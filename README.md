# Game Media — ПЗ1 «Middleware и шаблонизаторы»

Ветка `pz21`, вариант 13: журнал запросов хранится в **файле** `logs/requests.log`.
Публикации ПЗ находятся в массиве `data/items.js`, после перезапуска возвращаются начальные записи.

## Запуск

```bash
npm install
npm start
```

По умолчанию: http://localhost:3001. Для API предыдущих лабораторных используется существующий `.env` с `DATABASE_URL`, `JWT_SECRET` и при необходимости `PORT`. Секреты не коммитятся. Миграция таблицы журнала из ранней версии сохранена в истории, но текущее логирование её не использует.

## Проверка

- `/` — список публикаций; `/item/1` — детали, лайки и время создания.
- `/add` — переход на `/login`; `/add?auth=1` — форма. Это учебная имитация входа.
- `POST /add?auth=1` — принимает `title`, `game`, `mediaType`, `mediaUrl`, `description`, `likesCount` (формат формы или JSON).
- Проверяются пустые/пробельные поля и длина: название до 100, игра до 80, адрес медиа до 2048, описание до 1000, значение типа до 20, счётчик лайков до 7 символов. Длина исходной строки проверяется до преобразования в число. У лайков `type="text"`, `inputmode="numeric"`, `maxlength="7"`: браузер ограничивает и вставку огромного числа. Техническое требование к счётчику — целое неотрицательное число. Проверки формата адреса и списка допустимых значений убраны. На странице деталей только адрес http/https становится активной ссылкой, прочие значения показываются экранированным текстом.
- При ошибках: HTTP 400, все сообщения над формой, введённые значения сохранены. При успехе: 302 на главную. Сервер назначает ID и уникальное время создания, клиент не может их задать.
- `/missing` и `/item/999999` — страница 404.
- Ссылка «Демонстрация 500» в закреплённой шапке ведёт на `/test-error?auth=1`. Ответ — EJS-страница 500 с пояснением и навигацией.
- `/logs?auth=1` — последние 100 записей, прочитанных из файла журнала.

## Ограничение ресурсов

Все числовые пределы находятся в `config/validation.json`.

- Тело JSON/формы до 32 КиБ, не более 12 параметров формы. Превышение возвращает 413 с оформленной страницей, для API — JSON.
- Не более 120 динамических запросов за минуту с одного IP. Следующие получают 429 и `Retry-After`. Ограничитель стоит перед журналом и маршрутами. CSS доступен независимо от блокировки.
- Массив содержит не более 1000 публикаций. При заполнении форма объясняет необходимость перезапуска учебного сервера.
- Журнал до 1 МиБ, затем переносится в `requests.log.1`. Хранится один предыдущий файл. Запись и ротация выполняются последовательно. Для просмотра читается только хвост до 64 КиБ и выводится до 100 записей.
- Длинные неразрывные строки переносятся внутри карточки.

Это ограничения одного учебного процесса. Счётчик запросов сбрасывается при перезапуске. Для защиты опубликованного сайта от распределённой сетевой атаки нужны средства хостинга или прокси.

При проверке отправьте поле длиннее `maxlength` напрямую через Postman: сервер вернёт 400. Тело более 32768 байт даст 413. После 120 запросов за минуту с одного IP следующий даст 429. После окончания минуты доступ восстановится. Не проводите эти проверки на чужих адресах.

## Логирование и обработка ошибок

Каталог и файл создаются автоматически. Формат — JSON Lines: время запроса, метод, URL. Запись выполняется **до** маршрута. Если файл нельзя открыть или записать, `next(error)` передаёт управление обработчику 500; исходное действие не выполняется. Статика подключена раньше логирования: CSS страницы ошибки остаётся доступным даже при сбое файла. Подробная причина ошибки выводится в консоль; пароли, тела запросов и Bearer-заголовки не записываются.

Для проверки сбоя на отдельном экземпляре сервера задайте `REQUEST_LOG_FILE` путём к каталогу вместо файла. Запрос вернёт 500, сервер продолжит работу. Логи исключены из Git.

Порядок middleware: статика → ограничитель частоты → логирование в файл → разбор JSON/форм с ограничением размера → маршруты → 404 → обработчик ошибок с четырьмя параметрами.

API `/posts`, `/auth`, `/profile`, `/admin` предыдущих лабораторных сохранено и использует JWT независимо от учебного входа ПЗ.
