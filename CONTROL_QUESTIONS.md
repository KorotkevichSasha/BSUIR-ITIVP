# Ответы на контрольные вопросы

1. **Что такое ORM?** ORM сопоставляет таблицы базы данных с объектами программы. Она уменьшает количество ручного SQL и упрощает CRUD, миграции и связи. Недостатки: дополнительный уровень абстракции, возможные неоптимальные запросы и необходимость изучать API ORM.

2. **Как Sequelize преобразует названия моделей в таблицы?** По умолчанию название модели переводится во множественное число: модель `Post` использует таблицу `Posts`. Это можно изменить параметром `tableName` или `freezeTableName`.

3. **Как выполнить поиск с условием?** Например: `Post.findAll({ where: { mediaType: 'video' } })`.

4. **Что такое миграции?** Это файлы с последовательными изменениями схемы базы. Метод `up` применяет изменение, а `down` отменяет его. Миграции позволяют одинаково обновлять базу на разных компьютерах.

5. **Как создать связь один-ко-многим?** Например, один пользователь может иметь много публикаций: `User.hasMany(Post)` и `Post.belongsTo(User)`. В таблице публикаций для этого хранится внешний ключ `userId`.

6. **Как выполнить пагинацию?** `Post.findAll({ limit: 10, offset: 20 })`. `limit` задаёт количество записей, `offset` - количество пропускаемых записей.

7. **Как обработать ошибку уникальности?** Перехватить `SequelizeUniqueConstraintError` в `catch` и вернуть клиенту статус `400` или `409` с JSON-ошибкой.

8. **Чем отличаются findByPk и findOne?** `findByPk(id)` ищет по первичному ключу. `findOne({ where: ... })` возвращает первую запись, подходящую под произвольное условие.

9. **Как добавить кастомный метод?** Метод экземпляра добавляется в класс модели, например `getShortDescription()`. Статический метод объявляется с ключевым словом `static`.

10. **Какие связи поддерживает Sequelize?** `belongsTo`, `hasOne`, `hasMany` и `belongsToMany`.
